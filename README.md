Возможности работы с каналами:

- скачивалка ВСЕГО. Скачать ВСЕ посты канала от начала до конца
- докачивалка. Через некоторое время после закачки всего, докачать новое
- скачивание приложений к постам (фото, может еще что-то).
- распечатать большой пост в md. `print_from_shelve`
- распечатать много постов подряд в md (подходит для коротких новостей). `print_from_shelve`
